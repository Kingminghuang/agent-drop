# 坚果云 WebDAV 会话同步适配设计

> 状态：设计稿，尚未实现。本页只负责坚果云 WebDAV 的请求映射、提交与验证义务。[阶段 2 方案](../session-sync-phase-2.md)拥有直连服务共同语义。这里记录的服务行为不能推广到其他 WebDAV 服务，且须在实施时以真实服务复核。

## RFC 4918 基线与坚果云偏差

[RFC 4918](https://www.rfc-editor.org/rfc/rfc4918.html)定义 WebDAV 方法和头部的互操作语义；本适配器遵循这些语义。坚果云特有行为按真实服务实测并记录在本页；服务端行为与 RFC 不一致时，按服务端实测结果做兼容，但不能把这种兼容当作其他 WebDAV 服务的能力。

- `PROPFIND` 请求显式发送 `Depth: 1`，客户端递归访问每个子集合；不请求 `Link: …; rel="next"` 中的下一页。RFC 4918 没有定义分页机制；`Depth: infinity` 表示整个成员树，而坚果云记录的实现只返回一层，因此也不能用它替代分页。若响应带 `rel="next"`，该目录和整次远端扫描标记为不完整；不得据此宣称同步完成、判断对象已删除或执行清理。
- 同一路径允许后一次成功写入替换不同内容。RFC 4918 的 `MOVE` 默认即允许覆盖；可显式发送 `Overwrite: T`。坚果云记录称当前实现忽略该头，目标冲突时可能返回 `405`/`409`；此时比较目标，若内容不同则可用该服务会覆盖已有文件的 `PUT` 替换。替换后必须读回并校验摘要；不要求保留被替换的旧字节。
- `PUT` 到已存在的文件会替换文件；暂存名须为本次提交新生成且不可复用。ETag 是 HTTP 条件请求/缓存验证器，不是内容摘要或跨设备顺序号；坚果云对 ETag 的精确字符串比较属于服务行为，不能据此替代内容校验。
- 本适配器不依赖 `LOCK` 或 `PROPPATCH`。尽管坚果云 `OPTIONS` 记录返回 `DAV: 2`，实现参考中列出的锁和属性行为不足以视为 RFC 4918 Class 2 保证。

## 连接与凭据

用户提供服务地址、已存在的 sandbox、sandbox 内专用 `remoteRoot`、账号与应用专用密码（ASP）。ASP 只进操作系统凭据库，配置及日志不含密码。连接前用只读请求确认地址、账号、sandbox 和根目录；特别是先列出 `/dav/` 并校验 sandbox 已存在，避免拼错名称后 `MKCOL` 意外创建另一个 sandbox。`remoteRoot` 不能为空，也不能指向 sandbox 根。HTTP 请求不带凭据跟随重定向；响应中的 `href` 解码后必须仍在目标 sandbox 内。

坚果云标准 DAV 面使用应用密码，不能按 OAuth token 生命周期实现 `refresh` 或 `revoke`。401 表示当前凭据不可用，停止传输并提示重新录入；“断开连接”清除本地凭据，并提示用户在服务端撤销 ASP，不能谎称已经远端撤销。RFC 4918 不定义坚果云的认证与路径行为，这些行为须按真实服务核验。

## 发现、读取和上传

远端发现从 `remoteRoot` 逐层发送 `PROPFIND Depth: 1`，每个目录只读取首个响应，不请求 `Link: …; rel="next"` 的下一页，并保留请求深度与属性。若任一目录返回下一页链接，扫描结果标记为不完整；可处理已返回且校验通过的对象，但不得因未列出的名称而推断对象不存在、宣称扫描完整或执行清理。此限制意味着单次响应容量内的目录才能完整发现；不把自动翻页或 `Depth: infinity` 当作回退。`resourcetype` 判定目录，不能用 `getcontentlength: 0` 区分目录与空文件。`getetag` 可能依赖成组请求 `resourcetype`、`getcontenttype`，也可能为空；ETag 仅作缓存与传输优化，不作内容真实性或跨设备顺序证明。`PROPFIND` 的标准语义见 [RFC 4918 §9.1](https://www.rfc-editor.org/rfc/rfc4918.html#section-9.1)；坚果云属性、截断和分页行为须按真实服务核验。

`GET` 返回的对象由同步服务按清单中的 SHA-256 校验。续传只使用已验证的 `Range` 形式；`416` 后丢弃续传状态重新读取。写入前将待上传字节存入本地持久日志，以获得精确 `Content-Length` 并支持进程重启；缺少长度或超过服务端单次上传上限时不得尝试静默截断。日志只记录状态码、摘要、字节数和耗时，不记录认证头、完整 URL 或会话内容。

## 候选提交协议与竞态

候选协议把最终对象的暂存名置于**同一 sandbox、同一父目录**：先 `PUT .dsh-tmp-<uuid>`，再将暂存对象 `MOVE` 到最终内容寻址名，并发送 `Overwrite: T`。同父目录限制来自该服务的实现映射；跨目录移动可能退化为复制加删除，不能用于发布。若坚果云拒绝对已有目标执行 `MOVE`，先比较目标；相同则视为幂等完成，不同则用 `PUT` 将完整待传字节写到最终路径并读回校验。目录只在确认 sandbox 已存在后逐层创建。替换可能使此前同路径的旧字节不可恢复；失败或读回不匹配时保留待传日志并报告失败。

提交前读取目标：已存在且字节相同则幂等跳过；已存在且不同则允许替换。尝试同目录 `MOVE` 时发送 `Overwrite: T`；若坚果云返回 `405 ResourceExisted` 或 `409 DuplicateName`，则用 `PUT` 覆盖最终路径。提交后读回最终对象并验证其摘要，再发布引用该对象的树清单。提交前检查不能决定并发写入的最终胜者；同一路径的后一次成功写入可以替换先前值，协议不保留旧字节。写入中断或摘要不匹配时不能发布树清单，也不能报告该对象已完成。`PUT` 与 `MOVE` 的标准语义分别见 [RFC 4918 §9.7](https://www.rfc-editor.org/rfc/rfc4918.html#section-9.7) 和 [§9.9](https://www.rfc-editor.org/rfc/rfc4918.html#section-9.9)；坚果云状态码和覆盖行为须按真实服务复核。

不用 `LOCK` 实现跨设备互斥，也不用 `PROPPATCH` 存状态。单机状态目录须由本地锁保护；多设备并发会话分叉仍由[阶段 1 的导入比较](../session-sync-phase-1.md#导出与导入语义)识别，不会因此覆盖本地 Session 历史。坚果云分页被禁用；首个 `PROPFIND` 响应可能不完整。同目录 `MOVE`、目标替换回退到 `PUT`、锁、属性和错误名都是坚果云专项行为，不作为其他 WebDAV 服务的通用能力。

## 错误与恢复

| 观察 | 用户可见结果与恢复 |
|---|---|
| 401，响应可能没有 XML 错误体 | 凭据失效；停止传输并要求重新录入 ASP |
| `400 TooBigEntity` | `SYNC_UPLOAD_TOO_LARGE`；保留本地待传字节，不产生已发布清单 |
| 403 配额不足 | `SYNC_QUOTA_EXCEEDED`；等待用户释放空间 |
| `MOVE` 对已有目标返回 405/409，或写入后摘要不匹配 | 目标不同则用 `PUT` 替换并读回校验；失败时保留待传日志并报告失败。被替换的旧字节不保证保留 |
| `PROPFIND` 返回 `Link: rel="next"` | 不请求下一页；标记扫描不完整，不据此执行清理或报告同步完成 |
| 503 或临时并发失败 | 有界退避重试；最终失败保留待传状态 |
| 远端响应越出 sandbox，或对象摘要错误 | 停止相关导入或发布并报告校验失败 |

错误状态与例外名须按真实服务复核；不能把所有 409、412 或 403 合并成“目标已存在”。索引可从远端清单重建，待上传日志不可从远端重建；日志丢失时显式告知用户哪些字节尚未确认上传。发现过程不跟进坚果云的分页链接；若服务截断目录结果，则该轮扫描不完整，目录时间剪枝不能补足遗漏项。

## 验证义务

- 用 fake DAV server 验证响应含 `Link: rel="next"` 时客户端不请求下一页且标记扫描不完整；注入暂存写入中断、跨目录移动、同名并发替换、401 空响应、上传超限、越界 `href` 和重启恢复。断言只有读回完整且摘要正确的对象才会被树清单引用，旧字节无需保留。
- 在真实坚果云环境验证 sandbox 检查、`PUT` 的长度与上限、同父目录 `MOVE` 的可见性、冲突后 `PUT` 替换和读回校验，以及目录截断标记和错误映射。fake 测试只能验证适配器应对模拟行为，不能证明生产服务提供该行为。
- 用同一同步包分别经 `dir` 与坚果云传输，比较导入后的逻辑事件、附件、父子关系和冲突结果；远端文件传输完成前的 `pending` 属预期状态。
- 测量全树扫描请求数、延迟和大附件限制。若单对象上传上限阻断阶段 2 验收，应设计并验证对象分块及清单最后发布；不能直接在服务端省略大附件。

以上验证完成前，此页保持“设计稿”状态，配置不得把坚果云后端展示为已支持。
